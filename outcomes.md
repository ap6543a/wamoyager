# Wamoyager Experiment Outcomes

## 1. Setup Time & Infrastructure
- Hardware and software setup requirements and friction encountered.

## 2. Setup Time & Associated Costs
- Time investment to get the system running end-to-end.
- Direct and indirect costs incurred during setup.

## 3. Platform-Specific Use Case Differences
- Platforms like ServiceNow (SNOW) reduce setup time but serve vastly different use cases.
- Impacts and change management considerations differ significantly across platforms.

## 4. Cost / Benefit Evaluation
- How do we measure and evaluate the cost vs. benefit of an agentic approach?

## 5. High-Value Areas
- In which areas would an agentic approach really be worth the investment?

## 6. Code Implementation vs. Off-the-Shelf Agent Builders
- When does a use case require custom code vs. an existing agent-building platform?

## 7. Agent vs. Deterministic Automation
- When does it make sense to use an agent over traditional deterministic automation?

## 8. Industry Infrastructure Gap
- The industry has not yet caught up to agents.
- Existing infrastructure is not built with agents in mind.
- Free tiers are insufficient for meaningful agentic work.
- Agentic autonomy is tied to taking actions — which requires microservices and significant human setup.

## 9. Prompting Still Matters
- An agent is only as good as the model it runs on.
- Prompt quality remains a critical factor in agent performance.

## 10. Impulse Toward Determinism
- Natural tendency to make agents behave deterministically.
- Guardrails and logic must be deliberately designed and built in.
